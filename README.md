# iPhone Store

A responsive iPhone and accessories storefront built with React, Vite, and Tailwind CSS. Product configuration, cart, discounts, and checkout are client-side demos; the cart is saved in `localStorage`.

## Run locally

```bash
npm install
npm run dev
```

## Verify a production build

```bash
npm run lint
npm run build
npm run preview
```

## Deploy

This project is ready for Vercel or Netlify using the standard Vite settings:

- Build command: `npm run build`
- Publish directory: `dist`
- Node.js: 20 or newer

Connect the GitHub repository to either host and deploy. Each host will provide a live URL after the first successful deployment.
